# 📊 Beauty Salon Database

This repository contains a SQL Server script for a **Beauty Salon Management System** database project.  
The SQL file generates a service report that shows the number of reservations and estimated income for each service.

> 📄 The project PDF report is not included in this repository.

---

## ✨ Features

- Reporting beauty salon services
- Calculating the number of reservations for each service
- Calculating estimated income for each service
- Using `LEFT JOIN` to include services with no reservations
- Using `GROUP BY` and aggregate functions
- Using a `Cursor` to iterate through results row by row
- Executable in SQL Server Management Studio

## 🧾 Prerequisites

To run this script, you need the following:

- SQL Server
- SQL Server Management Studio or Azure Data Studio
- A database named `beautysalondb`
- The following tables must exist in the database:
  - `Service`
  - `Reservation_Service`

Expected table structure:

```text
Service
-------
id
name
price
```

```text
Reservation_Service
-------------------
reservation_id
service_id
```

## 🚀 How to Run

### Method 1: Run in SQL Server Management Studio

1. Open `beauty salon db final.sql` in SQL Server Management Studio.
2. Connect to your SQL Server instance.
3. Execute the script.

The script uses the following database by default:

```sql
USE beautysalondb;
```

---

### Method 2: Run with sqlcmd

If the file name contains spaces:

```bash
sqlcmd -S localhost -d beautysalondb -i "beauty salon db final.sql"
```

If you rename the file without spaces, for example `beauty_salon_db_final.sql`:

```bash
sqlcmd -S localhost -d beautysalondb -i beauty_salon_db_final.sql
```

## 📊 Report Output

The report output includes the following columns:

| ServiceName | ReservationCount | TotalIncome |
|---|---:|---:|
| Haircut | 1 | 150000.00 |
| Makeup | 1 | 300000.00 |

Column descriptions:

- `ServiceName`: Name of the service
- `ReservationCount`: Number of reservations for that service
- `TotalIncome`: Estimated income generated by that service

---

## 🧠 Report Logic

The script first calculates the number of reservations and estimated income for each service using the following query:

```sql
SELECT
    s.name,
    COUNT(rs.reservation_id) AS TotalReservations,
    COUNT(rs.reservation_id) * s.price AS TotalIncome
FROM Service s
LEFT JOIN Reservation_Service rs
    ON s.id = rs.service_id
GROUP BY s.name, s.price;
```

Then, the result is processed using a `Cursor`, and each row is displayed individually.

Using `LEFT JOIN` ensures that services with no reservations are also included in the report.

---

## ⚠️ Important Notes

- If the `beautysalondb` database does not exist, the script will not run.
- If the `Service` or `Reservation_Service` tables do not exist, the script will fail.
- `TotalIncome` is calculated using the following formula:

```text
Number of reservations × Service price
```

- If there are no records in the tables, the report output may be empty.
